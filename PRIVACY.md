# Switchy Privacy Policy

Last updated: September 14, 2026

Switchy is a browser extension that provides a keyboard-driven switcher for the most recently used tabs in the current browser window.

## Information Switchy handles

Switchy handles limited browser tab metadata needed for that feature:

- tab IDs, titles, URLs, active state, and window association, to maintain the recent-tab order and activate the tab selected by the user;
- the user-selected keyboard shortcut; and
- browser-provided favicon data used to identify tabs in the switcher.

This information is processed and stored locally in the browser. Recent-tab IDs are kept in browser session storage, and the selected shortcut is kept in local extension storage. Switchy does not operate a server or analytics system.

## Sharing and collection

Switchy does not transmit, sell, rent, share, or disclose browsing data or shortcut settings to the developer, advertisers, analytics providers, or other third parties. Switchy does not use this information for advertising, profiling, or personalization. Switchy does not read webpage content, form data, cookies, passwords, or communications.

Chrome may provide favicon images through its built-in extension favicon service. Switchy does not send browsing data to a Switchy-controlled server.

## Permissions

Switchy requests only the permissions needed to display and operate the recent-tab switcher: `tabs`, `storage`, `scripting`, `favicon`, and access to normal webpages for its local content script. The extension's code and assets are packaged with the extension; it does not download or execute remote code.
